WEB DEV PART 3

This is my final stage in this assigmnent. I was given a task to build a website for a local retail store which
I named Quick-Shop. This retail store needed a website to sell their products which are fashion clothing.

So this is the my part 3 website doing what i have been assigned to do. So I needed to apply all the knowledge and research
that I have do in class and at home (while studying) to meet all the requirements the website will need. This part of the 
project needed more files to build a whole complete website that will be functional and easy to use for the customers and the 
stuff of Quick-Shop. 

The files that I used in this website project were contact.html , enquiry.html , robots.txt , index.html , scripts.js , style.css ,sitemap.xml and images. All these files I mentioned were an requirement for the POE to build/code this website.
